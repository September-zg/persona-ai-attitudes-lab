# Project instructions

- This is an educational/research exploration tool, not a clinical, medical, hiring, or diagnostic instrument.
- Do not invent participants, feedback, deployment URLs, test results, or psychometric validity claims.
- Keep scoring deterministic and defined in versioned source files; never ask an LLM to score responses at runtime.
- Minimize personal data: do not collect names, email addresses, or identifying metadata by default.
- Any claim of completion must include the command or evidence used to verify it. Distinguish implemented, verified, unverified, and blocked work.
- Never delete existing data, reset databases, or force-push without explicit authorization.
