# 数据目录

本目录主要存放数据说明。不要提交 `data.json`、参与者级别的原始回答、知情同意记录、姓名、邮箱或其他身份信息。

如果为了复现开发测试需要放入数据，必须明确标记为“合成数据”。当前的 `synthetic_responses_10.json` 只是计分检查用的示例，不能计入正式试点人数。这里也可以放数据字典或报告中使用的匿名汇总表，但不能包含直接身份信息。

本地服务器会把运行记录写入项目根目录的 `data.json`。它只是本地 JSON 数据存储，不是正式数据库，且已被 `.gitignore` 排除。正式试点或公开部署前，需要确定数据保存位置、保存期限、访问权限和安全导出方式。

正式试点前还要写清楚：未完成回答如何处理、谁可以访问数据、数据保存多久，以及如何执行删除请求。
