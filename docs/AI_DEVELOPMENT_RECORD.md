# AI 辅助开发记录

本文件是提交用的开发记录索引，完整的按时间排列的记录见 [`development-log.md`](development-log.md)。

## 问题拆分

1. 固定测量设计：五大人格结构、项目翻译的 Mini-IPIP 题目、AI 态度维度、作答选项和反向计分规则。
2. 实现参与者流程：知情同意、两部分问卷、必答检查、计分、结果和可选反馈。
3. 实现数据保存和汇总：浏览器回退、本地 Python JSON 接口、逐题分布、维度平均分、内部一致性、相关和反馈摘要。
4. 检查 AI 生成的行为：测试页面导航、未完成回答、反向计分、重复点击、服务端保存、数据清除范围和汇总解释。
5. 准备提交证据：试点评估清单、分析方法、技术报告、部署指南和 GitHub 提交指南。

## 重要提示词和决策

- 计分规则必须固定在版本化源码中，不能让 AI 在运行时决定分数。
- 项目属于教育/研究探索，不是临床、医学、招聘或诊断工具。
- 不编造参与者、反馈、部署网址、测试结果或量表有效性声明。
- 只收集必要信息，不把运行数据提交到代码仓库。

## 已知限制

当前服务器使用本地 JSON 存储。设置 `ADMIN_TOKEN` 后，研究者汇总接口受到共享令牌保护，但这还不是完整的账户系统和访问审计系统。中文人格题目是项目翻译，不能描述为经过验证的中文版本；AI 态度题是探索性题目。
