# 试点评估记录

## 目的和边界

本次试点用于检查网站能否被真实用户完成、题目是否清楚、计分和页面是否正常。它不是正式的心理测量验证，也不能据此宣称量表具有正式信度、效度或预测能力。

正式试点开始前，应确认研究者汇总中的合成记录为 0，或在分析时明确排除所有 `syntheticTest: true` 的记录。不要把自己重复测试、开发测试或合成数据当作参与者样本。

## 招募和同意

- 目标人数：至少 10 名彼此独立的真实志愿者。
- 发放方式：`待填写，例如班级群/同学私发/线下邀请`。
- 参与者只需知道这是教育/研究探索，不需要提交姓名、邮箱、手机号或其他身份信息。
- 记录匿名编号（如 P01、P02），不要记录能反推出身份的信息。
- 参与者可在提交前退出，反馈为可选项。

## 反馈分析

### 题目和说明理解

- 用户是否理解“与自己的符合程度”和“同意程度”的区别：待填写
- 是否有人询问反向题或选项含义：待填写
- 最常见的理解困难：待填写

### 可用性和导航

- 是否能顺利从首页进入问卷：待填写
- 是否能完成两部分问卷：待填写
- 未完成题目时提示是否清楚：待填写
- 结果页和反馈页是否容易找到：待填写
- 手机端遇到的问题：待填写

### 计分和数据

- 结果页是否成功显示：待填写
- 是否发现分数与回答不一致：待填写
- 是否发现重复提交、刷新丢失或保存失败：待填写
- 研究者汇总人数是否与完成提交数一致：待填写
- 是否存在异常模式（大量全选同一选项、极短完成时间等）：待填写

### 喜欢、问题和改进

- 用户最喜欢的功能：待填写
- 用户最不喜欢或最困惑的功能：待填写
- 重复出现的建议：待填写
- 下一版优先改进：待填写

## 证据保存

可以提交以下去标识化证据：

- 研究者汇总页显示的完成数和反馈数截图；
- 导出的汇总 JSON（确认其中没有姓名、邮箱、手机号和 IP）；
- 上面的匿名完成记录和反馈汇总；
- 典型问题和改进建议的归纳。

不要提交参与者身份信息、管理员令牌或包含个人信息的原始截图。试点结束后应导出并安全保存数据；当前 Render 免费服务使用本地 JSON，不能当作长期研究数据库。
