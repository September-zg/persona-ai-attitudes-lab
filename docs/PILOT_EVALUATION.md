# D. 真实用户试点评估

## 1. 目的、招募与证据

正式试点统计固定使用 11 条独立参与者记录和 7 条反馈。服务器上后续产生的测试记录不计入本节分析；研究者页面的实时总数可能因此高于本报告。

本次试点检查参与者能否使用平台完成问卷、理解题目与结果，并收集下一版改进线索。它不是正式心理量表验证。

- 日期：2026-09-13。
- 招募方式：项目负责人将测评链接发送给不同朋友，自愿参与。
- 独立性：项目负责人在本次核对中确认，11 条提交来自不同的真实参与者，不是自测或同一人重复提交。
- 系统证据：从需要管理员密码的 `/api/summary` 导出 11 条回答、7 条反馈；合成标记记录 0 条，完整有效回答 11 条。
- 公开证据：[pilot-summary.json](evidence/pilot-summary.json)。包含逐题分布、维度分布与统计量，不包含身份、逐人的原始答案、提交时间或自由文本原文。
- 原始导出由负责人在本机保管；汇总文件中的 SHA-256 可用于核对其来源。复现命令：`node tools/analyze-export.cjs 私有导出文件.json 汇总文件.json`。

后台数据能证明 11 条完整提交，参与者彼此独立则依赖招募者的确认；不把浏览器编号当作自然人的可靠身份证明。

## 2. 完成和数据质量

| 指标 | 观察结果 | 解释 |
|---|---:|---|
| 完整提交 | 11 | 每份均含 26 个有效整数答案 |
| 反馈记录 | 7 | 7 条都有文字意见 |
| 反馈覆盖 | 7/11 = 63.6% | 基于独立参与者确认；不是问卷完成率 |
| 整体操作评分 | 4.14/5，n=7 | 旧版仅收集此单项，不能代替所有可用性指标 |
| 合成/无效记录 | 0 / 0 | 未见合成标记或缺失/越界答案 |
| 全部题目选择同一原始选项 | 0 | 只是简单异常模式检查，不足以证明回答认真 |
| 开始人数、退出人数、用时 | 未记录 | 不能计算完成率或评价极短作答 |

本次重新按 `scoring.py` 核算全部回答，并与存储的分数比较。核对结果及命令见 [验证记录](verification.md)。正式评估不能用测试样本替代这些真实记录。

## 3. 用户反馈如何影响修改

以下是对 7 条原始意见的去标识化归纳，一条意见可涉及多项；未进行正式编码一致性评估。

| 反馈发现 | 依据 | 本次处理 | 验证范围 |
|---|---|---|---|
| 界面简洁、排版清楚得到认可 | 多条意见肯定界面或排版 | 保留蓝白卡片、两步问卷和两段缩进说明 | 本地桌面及窄屏检查 |
| 题目希望更具体，或希望增加题目 | 两条意见提出内容丰富度问题 | 报告承认 AI 题每维仅两题且内容较宽；保留本次题目，后续版本再内容审查 | 没有宣称已提高测量效度 |
| 希望更直观地展示分数 | 一条较长意见提出图表建议 | 增加五大人格图、维度分数解释和后台分布图 | 本地浏览器流程测试 |
| 不理解结果代表什么、两部分有什么联系 | 一条意见明确表达结果困惑 | 结果页解释“回答倾向”、说明研究问题，并明确不能据此推荐工作 | 尚未向原试点参与者复测 |
| 建议增加 AI 解读、标签或人口信息 | 一条意见同时提出这些可能方向 | 本次保留确定性解释与最少数据收集；作为后续研究设计讨论 | 未增加职业、年龄或身份采集 |
| 对体验没有特别印象 | 一条简短中性意见 | 纳入整体评价，不改写成好评 | 保留其 3/5 评分 |

新版增加“说明清楚、题目易懂、操作容易、结果易懂、整体满意”五项可选反馈。这些是**改进后的采集工具**，旧试点没有收集的四项仍为 n=0，不补造分数。

## 4. 分数描述

| 维度 | 均值 / 5 | Cronbach α |
|---|---:|---:|
| 外向性 | 2.75 | 0.45 |
| 宜人性 | 3.64 | 0.24 |
| 尽责性 | 3.43 | -0.80 |
| 神经质 | 2.66 | 0.49 |
| 开放性 | 3.59 | 0.75 |
| 感知效益与使用意愿 | 4.18 | 0.77 |
| 信任 | 3.14 | 0.72 |
| 风险顾虑 | 3.45 | 0.31 |

这些均值描述当前样本对各题组的回答，不能据此评价人格优劣。AI 的效益/使用意愿较高，同时存在风险顾虑，并不矛盾。

尽责性 α 为负。此次代码检查和测试已确认反向键一致，负值仍存在，所以不能把它简单归因于“忘了反向计分”。题目含义、翻译、少量题目与小样本都值得复核。没有修改参与者答案，也没有删除低 α 题来美化结果。

人格 × AI 态度的全部 15 组相关保存在汇总证据中。例如宜人性与信任 r≈0.78，但样本只有 11 人、比较较多且部分题组内部一致性不足；该数值仅是探索线索，不是稳定关联、显著性发现或因果证据。

## 5. 能得出什么、还不知道什么

11 位受邀者完成了平台记录，7 人愿意提供反馈，说明初版流程至少对这批人可用。正面意见集中于简洁界面；最明确的问题是结果解释不足，以及题目希望更具体。

仍不知道：邀请总数和开始总数、未完成原因、设备分布、网络失败发生率、每人的完成用时，以及新版解释是否真正解决困惑。未建立这些记录，不能写成“没有发生问题”。朋友便利样本和自愿反馈也可能产生选择偏差。

下一轮应优先邀请原先觉得结果不清楚的参与者重测新版，以结构化反馈和完成用时验证修改；同时扩大招募渠道、审查翻译和题目内容。保存期限与删除流程需在下一轮正式数据收集前明确。
