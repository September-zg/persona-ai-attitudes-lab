# 试点评估

请使用详细操作清单 [`pilot-evaluation.md`](pilot-evaluation.md)。正式评估必须在删除所有合成验证记录后进行，并至少邀请 10 名真实且彼此独立的志愿者。

需要记录以下内容，但不要记录参与者身份：

- 完成和未完成的人数；
- 参与者是否理解说明和题目；
- 结果和反馈提交是否正常；
- 评分反馈以及重复出现的改进建议；
- 发现的导航、移动端或计分问题。

不能把合成数据当作试点证据，也不能根据小样本试点宣称量表已经完成正式信度或效度验证。

## 提交前填写区（必须使用真实记录）

- 评估日期：待填写
- 发放方式：待填写
- 完成提交人数：待填写（至少 10 名彼此独立的志愿者）
- 未完成或中途退出人数：待填写
- 完成率：待填写
- 反馈评分数量与平均分：待填写
- 反复出现的可用性问题：待填写
- 题目理解问题：待填写
- 计分或导航异常：待填写
- 下一版改进：待填写

证据可以使用去标识化的完成计数、研究者汇总页截图或导出汇总；不要提交姓名、邮箱、手机号、IP 地址等身份信息。合成验证数据和本地自测记录不能替代这部分证据。
