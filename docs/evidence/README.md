# 试点评估证据

本目录存放可公开核验的、去标识化的试点汇总证据。

- [`pilot-summary.json`](pilot-summary.json)：由研究者 API 导出的汇总结果
- 记录：11 条完整提交、7 条反馈
- 排除：0 条合成记录、0 条无效记录

文件只包含汇总统计、题目分布和可靠性/相关性结果，不包含姓名、邮箱、逐人原始答案、提交时间或自由文本原文。原始导出由项目负责人私下保管。`sourceSha256` 用于核对汇总来源，不代表参与者身份验证。

这些数据来自小规模便利样本试点，仅用于检查流程和描述性分析，不能作为正式量表验证或因果结论。


## 数据口径

`pilot-summary.json` 是正式试点的固定快照，统计 11 条独立参与者记录和 7 条反馈。部署后产生的额外测试记录不纳入该快照；因此研究者页面实时总数可能与本证据文件不同。正式提交时应同时查看本说明和试点评估报告。
