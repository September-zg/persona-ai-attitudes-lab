# 本地功能测试清单

请在 `http://localhost:8000/index.html` 上逐项执行，并记录实际结果。

## 流程测试

- [ ] 首页能打开，显示用途、数据说明和非诊断声明。
- [ ] 未勾选同意时点击开始会被阻止。
- [ ] 勾选同意后能进入人格问卷。
- [ ] 人格问卷漏答时不能进入下一部分。
- [ ] 完成人格问卷后能进入 AI 态度问卷。
- [ ] AI 态度问卷漏答时不能查看结果。
- [ ] 完成全部题目后能显示结果页。
- [ ] 点击提交反馈后会跳转感谢页。
- [ ] 感谢页能返回首页和研究者汇总。

## 数据测试

- [ ] 终端出现 `POST /api/responses 201`。
- [ ] 终端出现 `POST /api/feedback 201`。
- [ ] 研究者汇总能读取参与者人数。
- [ ] 每题回答分布的总数与响应数量一致。
- [ ] `data.json` 中出现一条 response 和一条 feedback。
- [ ] 导出 JSON 能下载文件且内容可读。

## 计分测试

- [ ] 全部选择 3 时，各维度结果为 3.00。
- [ ] 反向题选择 1 时，该题计分为 5。
- [ ] 反向题选择 5 时，该题计分为 1。
- [ ] 运行 `python3 scoring_examples.py` 显示 `scoring specification checks passed`。
