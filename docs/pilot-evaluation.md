# 试点评估操作清单

以下工作需要项目负责人亲自完成，因为它们涉及真实参与者和真实反馈，不能由 AI 代替或伪造。当前仓库中的虚拟验证数据必须先清除。

1. 在浏览器刷新 `index.html`，完整完成一次测评，确认结果页、反馈表和研究者汇总页可以打开。
2. 将页面分享给至少 10 名彼此独立的志愿参与者，并说明这是教育/研究探索，不是诊断。
3. 请每人独立完成问卷和可选反馈。记录完成/未完成，不记录姓名、邮箱等身份信息。
4. 在研究者汇总页查看人数、维度平均分、逐题分布和反馈平均分。
5. 点击“导出 JSON”，将文件保存到安全位置；不要公开原始回答。
6. 在报告中如实记录样本量、完成率、用户问题、异常作答模式和下一版改进项。不要把小样本结果宣称为正式量表验证。

## 当前限制

本地服务器把数据写入项目目录的 `data.json`，浏览器 `localStorage` 只作为 API 不可用时的回退。该 JSON 文件不是正式数据库；服务器可通过 `ADMIN_TOKEN` 保护汇总 API，但这不是完整的账户和审计系统，因此公开多人试点前仍需完成 HTTPS、令牌管理和访问控制检查。
