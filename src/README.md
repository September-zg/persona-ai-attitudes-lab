# 源码目录说明

当前原型为了保持无构建步骤的启动方式，把浏览器和 Python 的入口文件放在项目根目录。运行 `python3 server.py` 后，服务器会直接提供根目录中的 `index.html`。

主要源码文件如下：

- `app.js`、`styles.css`：参与者页面和研究者汇总页面；
- `index.html`：页面结构、知情同意和问卷内容；
- `server.py`：本地 JSON 接口和服务端计分校验；
- `scoring.py`：统一、固定版本的计分规则，供服务器和测试使用。

当前实现包含知情同意、问卷、与页面分开的计分逻辑、参与者结果图表、数据保存和研究者汇总页面。设置 `ADMIN_TOKEN` 后，汇总接口必须提供对应的 `X-Admin-Token`。

这只是一个共享令牌保护，不是完整的账户系统和访问审计系统。公开部署时仍需使用 HTTPS，并妥善保管令牌。
