# 源码位置

> **版本与证据范围（2026-09-13）**：当前恢复版入口只加载 `app.js`，题目、计分和页面渲染均包含在该文件中；`questionnaire.js`、`analysis.js` 是仓库中保留的模块化开发代码，不能将其测试通过等同于当前线上 UI 全部通过。历史版的返回修改、五项反馈、用时统计、保存失败阻止跳转和后台维度分数分布不应宣称为恢复版已实现。恢复版包含均值和逐题分布；均值不等于维度分数分布，此项任务要求仍需补齐或明确列为不足。下文涉及“新版”的功能和测试记录应按历史开发记录阅读。


可运行源码在仓库根目录，保持 Python 标准库直接启动：

- `index.html`：加载前端资源；
- `questionnaire.js`：题目、维度、反向键与反馈字段；
- `app.js`、`styles.css`：参与者流程、结果图、研究者页面与样式；
- `analysis.js`：确定性前端计分、分布与探索性统计；
- `server.py`：保存、权限、前端资源白名单、备份追加恢复；
- `scoring.py`：服务端固定计分规则。

本地复现见根目录 README。无需为了匹配模板把源码搬进 src；搬动时必须同步启动路径与测试。


## 与参考模版的差异

参考模版建议将源码放入 `src/`，本项目为了保持 Render 启动命令简单而保留根目录结构。这是有意的结构选择，不影响功能；README、测试和部署命令均按当前根目录结构编写。
