# 测试说明

项目包含不依赖第三方库的服务端计分测试。

运行全部测试：

```bash
python3 -m unittest discover -s tests
python3 scoring_examples.py
```

这些测试会检查多种情况，而不是只检查一种固定回答：

- 正向题和反向题的计分；
- 题目是否分配到正确的子量表；
- 维度平均分是否正确；
- 合法的最低分和最高分；
- 缺失回答和非法回答；
- 配置管理员令牌时，研究者汇总接口的访问保护。
- 单独改变某一个维度时，其他维度不被连带改变；
- 多个维度同时出现不同回答时能分别计算；
- 布尔值、小数等非整数回答会被拒绝；
- 合成数据包含 1 到 5 的不同分数水平。
- 每一道题的边界值都按其正向或反向计分键核对；
- 答案字段顺序变化不会改变结果；
- 空值、数组、文字和数字等非对象答案会被拒绝；
- 维度平均分不会在单题阶段提前四舍五入。
- 计分配置包含 26 道题且题号没有重复；
- 未知题号会被拒绝，计分函数重复调用不会修改原始答案。

`scoring_examples.py` 还包含一个手工计算示例，用来确认独立计算结果与程序结果一致；完整场景列表见 `data/test-scenarios.md`。浏览器完整流程目前仍需按照 `docs/local-test-checklist.md` 手动测试。
